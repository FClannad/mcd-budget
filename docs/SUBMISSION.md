
不要写没完成的功能、虚构用户数量或未测量的节省比例。

## 真实流程演示

1. 打开「真实预算」，说明只读、非订单，只比较有限候选，不承诺全菜单最省。
2. 输入公共地标，选择营业门店；展示菜单来源、时间及参考标价提示。
3. 设置预算、人数、主食与饮品要求，确认是否参考本店可用券，点击自动推荐；说明多次官方查询可能需要等待。
4. 展示官方实付升序、实际规格、预算余额/缺口与有效时间；未核价候选不参与排名，超预算参考单列。
5. 展示券面板：有完整同餐单基线时说明增量节省，否则明确不能计算；券餐若比最低方案更贵则解释多付金额。可保存两份对比，或改用下方手动核价。
6. 可另切换「预算实验室」展示 22 元与 25 元的凑单反例及 PNG 水印，明确这是自建样例，不是官方优惠。

实时接口可能因时段、菜单或网络变化而失败，应原样说明；备用历史截图须展示日期并标明过期，不能剪成现场核价成功。
